# Edvibe Interactive Periodic Table

A modern, interactive periodic table of elements built for students, educators, and science enthusiasts.

## Overview

The Edvibe Interactive Periodic Table is a fully responsive, web-based educational tool featuring all 118 chemical elements with detailed properties, smart filtering, real-time search, and a premium dark-themed interface. The project reflects Edvibe's mission to revolutionize education by integrating cutting-edge technology with impactful pedagogy.

## Features

- Complete coverage of all 118 elements with accurate data
- Interactive element cards revealing atomic number, weight, electron configuration, and oxidation states
- Smart filtering by metals, nonmetals, metalloids, states, groups, and periods
- Real-time search by element name or symbol
- Responsive layout for desktop, tablet, and mobile
- Premium glassmorphism interface with neon cyan accents
- Element detail view with comprehensive property data
- Eye-friendly dark theme

## Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- Internet connection for CDN resources

### Run Locally

```bash
git clone https://github.com/edvibeke/periodictable.git
cd periodictable
```

Open `index.html` directly in a browser, or serve the directory with any static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Usage

- Click any element to open its detailed property panel.
- Use the filter buttons to narrow results by category, state, group, or period.
- Type in the search field to find elements instantly by name or symbol.
- Toggle the intro section for additional context about the project.
