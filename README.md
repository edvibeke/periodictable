## Overview

The Edvibe Interactive Periodic Table is a fully responsive, web-based educational tool that features all 118 chemical elements with detailed properties, smart filtering, real-time search, and a premium dark-themed interface.

This project reflects Edvibe's mission to revolutionize education by integrating cutting-edge technology with impactful pedagogy.

---

## Features

| Feature | Description |
|---------|-------------|
| Complete Table | All 118 elements with accurate data |
| Interactive Elements | Click any element to view detailed properties |
| Smart Filtering | Filter by metals, nonmetals, states, groups, periods |
| Real-time Search | Find elements by name or symbol instantly |
| Responsive Design | Works on desktop, tablet, and mobile |
| Premium UI | Glassmorphism with neon cyan accents |
| Element Details | Atomic number, weight, configuration, oxidation states |
| Dark Theme | Modern, eye-friendly dark interface |
